# МегаФон для мигрантов

Демонстрационный лендинг тарифов **«Тёплый приём»** — связь в России и звонки домой для гостей из стран СНГ.

Это не официальный сайт МегаФона. Цены и пакеты ориентированы на публичные условия линейки «Тёплый приём» и нужны, чтобы показать продукт.

## Что на странице

- Тарифы S / M / L с минутами по России и пакетом «домой»
- Цены на звонки в Узбекистан, Таджикистан, Киргизию и другие страны СНГ
- Как оформить SIM в салоне за 15 минут
- Форма заявки на обратный звонок
- Языки: русский, узбекский, таджикский, кыргызский

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:43123](http://localhost:43123).

Сборка:

```bash
npm run build
npm start
```
